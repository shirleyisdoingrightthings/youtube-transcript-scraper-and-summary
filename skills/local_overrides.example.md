# 本地专属编辑配置示例（Local Editorial Overrides Example）

> 如需在发布稿中使用自定义署名、频道品牌名或专属封面风格，请将本文件复制为 `skills/local_overrides.md`（已在 `.gitignore` 中忽略，不会提交到 Git）。

- **署名行**：
  - `👩 编译：<你的译者署名>`
  - `🧑‍🎨 排版：<你的排版署名>`
- **品牌头图占位**：`🖼️ [图片占位：品牌头图]`
- **编者按前缀**：`**编者按：**`（或 `**<你的频道名>编者按：**`）
- **封面默认调性**：Editorial Dark Motion-Blur（暗冷电影感长曝光 / 动态模糊）
